เหตุผลที่อยากเรียน Full stack web development
ต่อยอดทักษะเดิมอย่างก้าวกระโดด: นำพื้นฐาน Java, Python และ Data Structures ที่มี มาเชื่อมต่อกันเป็นระบบที่ทำงานได้จริงแบบ Complete System คุมได้ทั้งระบบ เข้าใจภาพรวมทั้งหมด ตั้งแต่การออกแบบหน้าตา UI, Logic หลังบ้านและ Database ไปจนถึงการ deploy บน Cloud เห็นผลลัพธ์ทันที: ได้สร้างชิ้นงานที่จับต้องได้ สั่ง Run แล้วเห็นหน้าเว็บตอบสนองทันที ทำให้สนุกและอินกับโปรเจกต์ได้ง่าย ความยืดหยุ่นในสายอาชีพ: ตลาดต้องการสูง ตอบโจทย์ทั้งการต่อยอดงานสาย Software, การทำ Side Project ของตัวเอง หรือการรับงาน Freelance

อะไรคือจุดอ่อน ที่ตนเองต้องพัฒนาเกี่ยวกับทักษะ Programming และ แนวทางการพัฒนา
จุดอ่อนสลับสับสนระหว่างภาษา เรียนทั้ง Java, Python และ Web Development พร้อมกัน ทำให้สับสน Syntax และแนวคิดเฉพาะของแต่ละภาษา แนวทางวางแผนก่อนเขียน (Design First): วาด Diagram หรือเขียน Pseudocode สั้นๆ บนกระดาษเพื่อเก็บ Logic และ Edge Cases ให้ครบก่อนแตะคีย์บอร์ด
จุดอ่อนพึ่งพาการสุ่มหา Bug ยังใช้ print() หรือไล่ดูโค้ดทีละบรรทัด แทนที่จะใช้ IDE Debugger อย่างคุ้มค่า แนวทาง ใช้ Debugger ให้ชิน ฝึกตั้ง Breakpoints และตรวจค่าตัวแปรผ่าน IDE แทนการพิมพ์สั่ง Output ออกหน้าจอ
